# Role: Frontend Developer

## 1. Responsibilities
Ship React/Next.js prod UIs, streaming AI chat, perf + a11y, BFF integration.

## 2. Required skills
TypeScript, React 19 / Next.js 15 (RSC, actions), Vite, Zustand, TanStack Query, tRPC, Zod, Tailwind, Vercel AI SDK, Playwright.

## 3. 90-day roadmap
- Days 0-30: TS strict, Next App Router, TanStack Query + Zod, `01-javascript-trending/frontend-frameworks/trending.md`.
- Days 30-60: Streaming chat with Vercel AI SDK, optimistic UI, error boundaries.
- Days 60-90: Perf (Lighthouse 90+), E2E, edge caching, feature flags.

## 4. Interview / Prod checklist
- [ ] RSC vs client component boundary
- [ ] Cache / revalidate strategy
- [ ] Bundle <200kb first load
